# TalkWithAI

A small, validation-first workspace for building AI-powered internal tools and customer-facing micro-products.

## Core operating principles

1. Start with the smallest useful version.
2. Only build when the purpose and usage are clear.
3. Validate direction in very small steps.
4. Optimize for fast, cheap delivery.
5. Keep the valuable part in reusable prompts, workflows, and customer context.

## Initial focus

This repository starts with two documents:

- `docs/assistant-operating-guide.md`: how the assistant should help plan and ship work.
- `docs/crm-mvp.md`: a smallest-possible CRM/database design for customers, usage, and important business connections.

## Suggested first build sequence

1. Capture one customer type.
2. Track one service offering.
3. Record one usage metric.
4. Invoice one customer manually.
5. Automate only after the manual workflow works.
